# みらい議会＠前橋市

前橋市議会の議案・議事（一般質問、委員会審査、討論、表決）を、公式資料をもとにわかりやすくまとめたサイトです。

- 公開中のページ: https://muse.ai/s/mirai-gikai-maebashi-shi-xixn6oxd5kh9cxk/-YH3T0WZJ_7GYS7hQleRGRScO5wr2f5wo-B1GayEiW4
- このリポジトリの `index.html` は、Museで作成した簡易版サイト（令和8年 3月・6月・9月定例会、議事ベース＋議案ドリルダウン対応）を書き出したものです。
- 政党チームみらいが運営しているものではありません。
